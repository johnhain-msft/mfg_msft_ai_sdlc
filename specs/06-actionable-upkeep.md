## 1. Objective and non-goals

### Objective
Amend SPEC-01, SPEC-02, SPEC-03 and SPEC-04 so that the live orchestrator instance (`johnhain-msft/mfg_msft_ai_sdlc`) and its engine (`johnhain-msft/ai-sdlc-factory`) produce judgement-based, source-backed pull requests instead of report-only or mechanical-only churn, port upstream Lab Studio UI and track additions safely into `johnhain-msft/portfolio` without exposing hosted authentication or session isolation, and cascade `johnhain-msft/gh-github-intermediate` mechanically through `npm run import:github-intermediate`.

Specifically, this specification defines:
1. **Mechanical `github-intermediate` edge (amending SPEC-01, SPEC-03, SPEC-04):** The `github-intermediate` project and dependency edge point at `johnhain-msft/gh-github-intermediate` (`initialBaselineSha: a5234874a0f708f81661a22e83e498bf1d047401`) with `mode: "mechanical"`, `provenanceFile: "public/github-intermediate/source.json"`, `importCommands: ["npm run import:github-intermediate -- <checkout>"]`, `buildCommands: ["npm run build", "STUDIO_ORIGIN=https://studio.example.com npm run build:catalog"]`, `allowedFiles: ["public/github-intermediate/**"]`, and the five portfolio verification gates. The preset therefore has three `mode: "mechanical"` edges (`ghec-admin`, `github-intermediate`, `ai-sdlc`) and two `mode: "ai-adaptation"` edges (`copilot-lab`, `pipeline-showcase`).
2. **Lab Studio UI & track cascade expansion with hosted auth protection (amending SPEC-01, SPEC-04):** The `copilot-lab` edge replaces `apps/lab-studio/client/src/labs/source.ts` and `apps/lab-studio/client/src/labs/lab*.tsx` in `allowedFiles` with `apps/lab-studio/client/src/labs/**`, `apps/lab-studio/client/src/components/Home.tsx`, `apps/lab-studio/client/src/components/Manual.tsx`, `apps/lab-studio/client/src/components/Rail.tsx`, and `apps/lab-studio/client/src/styles.css` (23 pairwise-disjoint entries), while adding `apps/lab-studio/client/src/hosted.ts` and `apps/lab-studio/client/src/components/AccountBar.tsx` to `immutableGates.zeroDiffPaths` on every AI-adaptation edge (19 entries). The `copilot-lab` `adaptationInstructions` explicitly require preserving hosted session and deep-link wiring (`loadWebsiteSession()`, `/workspace/status`, `resumePlace()`, `sourceRevisionUrl()`, `SOURCE_ONLY_EXERCISES`, `setupGuideUrl()`, `SETUP_GUIDE.note`, `MarkReadCard`, `sourceLabUrl()`, `sourceLabPath()`, and the `lab05.tsx` `consolidate-lessons` note), updating the 40-hex revision pin in `apps/lab-studio/README.md` and the 7-hex short SHA in `public/copilot-project.html`, and flagging any upstream changes to locked server files in the pull request body.
3. **Actionable upkeep and `changePolicy` (amending SPEC-01, SPEC-02, SPEC-04):** `driftAudit` accepts an optional `changePolicy: enum("corrections-only", "corrections-and-additions", "judge-and-flag")` (defaulting to `"corrections-and-additions"`) and an optional `model: string`; `dependencyEdges[]` accepts an optional `agentSandbox: { bashCommands?: string[] }` and an optional `model: string`. Under `changePolicy: "judge-and-flag"`, the drift and implementation prompts instruct the agent to apply source-backed updates, additions, and judgement calls directly in the pull request and list every judgement call under `## Judgement calls — review these` in the pull request body rather than deferring them to a report-only issue. The preset enables `changePolicy: "judge-and-flag"` on `gh-admin-msft`, `copilot-lab`, and `self-improving-agents` while keeping `gh_aw_schema_version` and `.github/workflows/**` strictly report-only in `copilot-lab` and keeping the ban on deleting any agent, skill, or prompt or editing `.github/workflows/self-improving-agents.*` in `self-improving-agents`.

### Non-goals
- No relaxation of `auto-merge: false`, `strict: true`, or `threat-detection`.
- No automated editing of `gh_aw_schema_version` or `.github/workflows/**` in `ms-mfg-community/day-in-the-life-copilot-lab`.
- No exposure of hosted Lab Studio client session modules (`hosted.ts`, `AccountBar.tsx`, `deeplink.ts`, `resume.ts`, `api.ts`, `App.tsx`, `controller.ts`, `store.ts`) or server sandbox modules (`index.ts`, `copilot-bridge.ts`, `sandbox.ts`, `sim-terminal.ts`, `skills.ts`) to AI cascade edits.
